# Explore the features

Beyond breakpoints and stepping, for example:

- **Exception Settings** and the **Exception Log** with the call stack at each throw
- **Set Next Statement**, **Step Into Target**, return values
- **Parallel Stacks**, freezing threads, **UI freeze detection**
- **Heap Snapshots**, the **Memory / CPU graph**, PerfTips
- **Decompile for Debugging**, Source Link and symbol servers
- WinForms: highlight a control, change its properties, break on its events

The guide lists every feature with use cases.
