# 機能を見てみる

ブレークポイントとステップ実行のほかに、たとえば:

- **例外設定** と、スロー時のコールスタックが残る **例外ログ**
- **次のステートメントの設定**、**Step Into Target**、戻り値の表示
- **並列スタック**、スレッドの凍結、**UI フリーズの検知**
- **ヒープ スナップショット**、**メモリ / CPU グラフ**、PerfTips
- **逆コンパイルしてデバッグ**、Source Link とシンボル サーバー
- WinForms: コントロールの強調表示、プロパティの変更、イベントで停止

ガイドに全機能とユースケースがまとまっています。
