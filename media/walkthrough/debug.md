# Start debugging

Set a breakpoint (click left of a line number in a `.cs` file) and press **F5**. The project is built, started as x86, and stops at the breakpoint.

While stopped: hover a variable for its value, use the **Variables**, **Watch** and **Call Stack** views, and **F10** / **F11** to step.
The **WinForms Controls** view lists the forms and controls of the stopped program.
