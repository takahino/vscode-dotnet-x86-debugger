# 環境を確認する

**netdbg** は同梱されており、.NET ランタイムは使いません。

デバッグするアプリのソースがあり、そのアプリを **ビルドできる環境**（SDK と、Framework 依存ならターゲットに合うランタイム）があれば、この拡張のための追加ランタイムは要りません。x86 ビルドでは、そのランタイムが `C:\Program Files (x86)\dotnet` に入っている必要があります。**.NET Framework 4.x** は .NET Framework だけでビルド・デバッグできます。エディット コンティニュだけ **.NET SDK 9 以降** が必要です。

**環境を確認** で、入っているもの・足りないものを一覧し、開いているフォルダーのプロジェクトも確認します。
